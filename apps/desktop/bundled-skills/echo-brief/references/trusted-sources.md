# Trusted Source Guidance

Use this order of trust when building Echo Brief items.

## Tier 1 (Primary)
- Official project changelog and release notes
- Official docs and vendor announcements
- Security advisories (vendor and ecosystem maintainers)
- Official package or framework repositories

## Tier 2 (Secondary)
- Reputable engineering blogs
- Independent technical analysis with citations
- Community issue threads with direct links to primary sources

## Tier 3 (Context Only)
- Social posts and forum chatter
- Aggregator summaries
- Opinion-only posts

## Requirements
- Every priority item needs at least 3 independent sources.
- At least 1 source must be Tier 1.
- If sources conflict, show conflict and lower confidence.
- Exclude promotional content from priority items unless tied to a verifiable release or advisory.

## Date Integrity
- Capture both:
  - publication date
  - event date (if different)
- Prefer latest authoritative correction when sources disagree.
